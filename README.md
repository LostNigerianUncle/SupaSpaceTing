# SupaSpaceTing
This is an orbital mechanics simulator written in Python that shows a space ship orbiting around planets and other celestial bodies. The user will be able to apply thrust burners to the spaceship to change its speed, and the user will be able to change its orbit around different planets nearby. Also at the start, there will be a rocket ascent section that will allow the user to launch a rocket into space and it will transition into the orbiting section.
Perhaps my biggest inspiration for this project would have to be the 2015 game Kerbal Space Program. Although I have not actually played the game, I have read about how the game's accurate aspects have captured the interest of figures in the space industry. Creating this project also stems from my own interest in aerospace engineering which I would really like to explore if I work hard enough and go to a good university that offers an aerospace degree.
